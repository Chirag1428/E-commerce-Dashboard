# E-commerce-Dashboard : An interactive business intelligence dashboard that provides insights into sales, customer behavior, and product performance in an e-commerce environment.

Dashboard Insights
1. The dashboard includes the following report pages:

2. Overview – High-level KPIs and trends

3. Sales Analysis – Revenue breakdown by time and region

4. Customer Analysis – Repeat vs new customers, top buyers

5. Product Analysis – Best sellers, stock movement

6. Profitability – Profit margins across categories
